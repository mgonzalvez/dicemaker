# Artwork Attribution

## Fractal Symbols: Board Game Library

- Creator: Felix Thalin
- Original library: <https://fractalsymbols.com>
- License: [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/)
- Included formats: SVG and PNG
- Use in DiceMaker: searchable source artwork that users may recolor, outline, scale, rotate, and combine with editable text on D6 faces.

The complete upstream license text and readme are preserved with the runtime artwork copies in:

- `assets/icons/Fractal-Symbols-Complete-Pack/`
- `assets/icons/FractalSymbols Icons Set/`

DiceMaker may normalize SVG paint attributes at render time so user-selected fill and stroke colors can be applied. The supplied source files remain preserved in the project. The local `TokenMaker/` folder is a development reference only and is not part of the published repository.
